# BAZI Tennis V3 — Free

No API key required.

- Historical analysis: Jeff Sackmann ATP/WTA datasets
- Today's schedule/live scores: ESPN public website JSON feed (unofficial)
- Automatic BAZI analysis for live/today matchups when player names can be resolved
- Auto-refresh default: 30 seconds

Note: ESPN's JSON endpoints are undocumented and may change, so the app includes graceful error handling.
